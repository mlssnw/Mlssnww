## Projetos em Destaque

### 🔬 LabFlow — QA & Testes (2026)
Sistema web de gestão inteligente de laboratórios acadêmicos para a UniSociesc/Grupo Ânima.

**Minha atuação como QA:**
- Análise estática do PRD (Product Requirements Document) com 21 páginas de regras de negócio
- Escrita de casos de teste funcionais com metodologia **BDD/Gherkin** (Dado/Quando/Então)
- Identificação de ambiguidades e lacunas nas regras de negócio antes da fase de desenvolvimento
- Cobertura de cenários críticos: Hard Constraints de capacidade, LGPD/Data Masking, regra FIFO de estoque, conflito de check-in e Kanban de laboratoristas
- Aplicação de **Análise de Valor de Limite** para testes de carga e precisão de estoque

**Tecnologias e conceitos envolvidos:**
`BDD` `Gherkin` `Shift-Left Testing` `Teste Estático` `LGPD` `RBAC` `FIFO` `Kanban` `Soft Delete` `Audit Trail`

### 📊 Dashboard AVC — Análise de Dados em Power BI (2026)
Dashboard interativo de análise de casos de AVC no Brasil, desenvolvido do zero como projeto acadêmico.

**O que foi construído:**
- Mapa coroplético do Brasil com dados por estado (UF)
- Gráfico de área empilhado com distribuição por **raça/cor e faixa etária** simultâneos
- KPI card com total de casos (103 mil registros)
- Top 5 cidades com mais casos
- 5 slicers independentes com cross-filtering configurado (UF, Tipo de AVC, Raça/cor, Sexo, Faixa Etária)

**Detalhe:** primeiro projeto desenvolvido do zero no Power BI, sem experiência prévia na ferramenta.

`Power BI` `Análise de Dados` `Saúde Pública` `Cross-filtering` `Data Visualization`
